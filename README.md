# 만천초 여비 정산 신청서

만천초등학교 **여비 정산 신청서(동승자 포함 서식)** 를 휴대폰·PC에서 바로 채우고, 인쇄·PDF로 뽑고, 구글 시트와 실시간으로 맞춰 두는 웹앱(PWA)입니다. 원본은 학교에서 쓰던 한글 서식 `여비정산신청서(동승자포함서식).hwp`입니다.

- 주소(공개 후): `https://hong3256.github.io/travel-settlement/`
- 구글 시트: [만천초 여비 정산 신청서](https://docs.google.com/spreadsheets/d/1MopKOI1ZnKJqORRTxNCiBot_5_nbC_GGAirCLQ1Yt5w/edit)

## 화면 구성 (원본 서식 그대로)

- `[붙임1]` · 제목 **여비 정산 신청서**
- **소 속**(기본값 `만천초등학교`, 수정 가능) · **직급(직위)** · **성 명**
- **출장(부임) 일정** — 일시(시작일·시각 ~ 종료일·시각, 날짜 선택), 출장목적, 출장(부임)지(경유지 포함)
- **숙박비 / 식비** — 상한액(지급받은 금액) · 실제 소요액 · 초과지출 사유
- **운 임 4행** — 일자(날짜 선택) · 교통편 · 출발지 · 도착지 · 등급 · 금액
- **동승자 현황** — 총 동승자수(신청인 포함, 자동 계산·직접 수정) · 동승자 명단 3행(소속·성명)
- 하단 — 「공무원여비규정」 제16조 제1항·제2항 신청 문구, 첨부, 신청일(날짜 선택, 인쇄 시 `2026년 11월 23일`), 신청인 성명 (인)

## 버튼

- **🖨️ 인쇄** — A4 세로 1장. 화면 장식·버튼은 인쇄에서 빠지고 입력한 값만 서식에 맞춰 찍힙니다.
- **📄 PDF 저장** — A4 세로 1장 `.pdf`로 내려받기. 파일명은 `만천초_여비_정산_신청서_{성명}.pdf`(성명이 없으면 신청일).
- **🔄 양식 초기화** — 소속(`만천초등학교`)만 남기고 입력값을 지웁니다. 동기화가 켜져 있으면 *이 화면만* / *화면과 구글 시트 함께* 중에서 고릅니다.
- **⚙️ 동기화 설정** — Apps Script 웹 앱 URL 넣기·연결 확인·공유 링크 복사.
- 상단 배지 — `🟢 실시간 동기화` / `🟡 로컬 저장`.

## 처음 설정 (3단계)

### 1) GitHub Pages 켜기

저장소 → **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `/ (root)` → **Save**.
1~2분 뒤 `https://hong3256.github.io/travel-settlement/` 로 열립니다.

### 2) 구글 시트에 Apps Script 붙이기

1. 시트에서 **확장 프로그램 → Apps Script**
2. 기본 코드를 지우고 `travel-apps-script.txt`(대화로 받은 파일) 내용을 그대로 붙여넣기
3. **저장 → 배포 → 새 배포 → 웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. 나온 `https://script.google.com/macros/s/.../exec` 주소를 복사

### 3) 앱과 연결

앱 오른쪽 위 **⚙️** → 주소 붙여넣기 → **저장**. 배지가 `🟢 실시간 동기화`로 바뀝니다.
함께 쓰는 사람에게는 **공유 링크 복사**로 만든 `?sync=...` 주소를 보내면 설정 없이 열립니다.

## 입력값 ↔ 시트 칸

| 항목 | 칸 | 항목 | 칸 |
| --- | --- | --- | --- |
| 소속 | B4 | 운임 1행 일자·교통편·출발지·도착지·등급·금액 | B11 · C11 · D11 · E11 · I11 · J11 |
| 직급(직위) | H4 | 운임 2행 | B12 · C12 · D12 · E12 · I12 · J12 |
| 성명 | L4 | 운임 3행 | B13 · C13 · D13 · E13 · I13 · J13 |
| 출장 일시 | C5 | 운임 4행 | B14 · C14 · D14 · E14 · I14 · J14 |
| 출장목적 | C6 | 총 동승자수 | C15 |
| 출장(부임)지 | C7 | 동승자 1~3 소속·성명 | G16·J16 / G17·J17 / G18·J18 |
| 숙박비 상한액·실소요·사유 | C8 · E8 · J8 | 첨부 | C21 |
| 식비 지급액·실소요·사유 | C9 · E9 · J9 | 신청일 | C23 |
| | | 신청인 성명 | C24 |

- 앱에서 고친 칸만 시트에 저장되고, 5초마다 시트의 변경을 받아옵니다(입력 중인 칸은 덮어쓰지 않음).
- 시트의 `출장 일시`(C5)는 `2026-12-01 09:00 ~ 2026-12-02 18:00` 같은 한 줄 문자열로 넣고, 앱이 다시 시작일·시각·종료일·시각으로 나눠 읽습니다.

## 참고

- 검색엔진에 노출되지 않도록 `noindex, nofollow`가 걸려 있습니다.
- 입력한 내용은 기기(localStorage)에 저장되고, 동기화를 켜면 시트와 함께 맞춰집니다.
- 원본 서식의 동승자 명단은 4행이지만 앱은 3행으로 만들었습니다(요청 사양). 시트의 4행(G19·J19)은 손으로 채울 수 있습니다.
- 서비스워커 캐시 버전: `travel-settlement-v1` (수정 후에는 숫자를 올리면 기존 설치 기기도 새 버전을 받습니다)
