# 만천초 국내여비 정산 신청서

만천초등학교 **국내여비 정산 신청서**를 휴대폰·PC에서 바로 채우고, 인쇄·PDF로 뽑고, 구글 시트와 실시간으로 맞춰 두는 웹앱(PWA)입니다.
원본은 `공무원보수 등의 업무지침 제9장 [별지 제3호 서식]` 국내여비 정산 신청서(`여비정산신청서.hwpx`)에 **동승자 칸**을 더한 서식입니다.

- 주소: `https://hong3256.github.io/travel-settlement/`
- 구글 시트: 「만천초 여비 정산 신청서」(계정 소유, 링크는 대화로 전달)

- **소 속**(기본값 `만천초등학교`, 수정 가능) · **직급(직위)** · **성 명**

- **동 승 자** — 총 동승자수(신청인 포함, 명단에서 자동 계산·직접 수정) · 동승자 성명 4칸

## 버튼

- **🖨️ 인쇄** — A4 세로 1장. 화면 장식·버튼은 인쇄에서 빠지고 입력한 값만 서식에 맞춰 찍힙니다.
- **📄 PDF 저장** — A4 세로 1장 `.pdf`로 내려받기. 파일명은 `만천초_국내여비_정산_신청서_{성명}.pdf`(성명이 없으면 신청일).
- **💾 저장** — 지금 화면의 양식을 통째로 이 기기에 저장하고, `양식 초기화` 옆에 `{날짜} {이름}` 칩으로 남깁니다(예: `2026-12-01 이진홍`). 신청일이 비어 있으면 오늘 날짜, 성명이 비어 있으면 `미입력`으로 표시됩니다. **같은 날짜·같은 이름이 이미 저장돼 있으면 새 칩을 만들지 않고 그 항목을 지금 입력 내용으로 덮어씁니다**. 칩을 누르면 그 양식이 화면에 불러와지고 구글 시트에도 함께 반영됩니다(단, **관리자 전용** — 잠금 상태에서는 비밀번호를 먼저 넣어야 열립니다). 최근 12개까지 보관합니다.
- **🔒 관리자 / 🔓 잠금** — 비밀번호 `0629`를 넣으면 관리자 모드가 열립니다. 관리자 모드에서만 저장한 양식(칩)을 눌러 **열람**할 수 있고, 양식마다 `×` 삭제 버튼이 나타납니다. `🔓 잠금`을 누르거나 새로고침하면 다시 잠깁니다.
- **🔄 양식 초기화** — 소속(`만천초등학교`)·총 동승자수(`1`)만 남기고 입력값을 지웁니다. 동기화가 켜져 있으면 *이 화면만* / *화면과 구글 시트 함께* 중에서 고릅니다.
- **⚙️ 동기화 설정** — Apps Script 웹 앱 URL 넣기·연결 확인·공유 링크 복사.
- 상단 배지 — `🟢 실시간 동기화` / `🟡 로컬 저장`.

## 마지막 입력이 남는 방식

- 입력칸을 고칠 때마다 **곧바로**(지연 저장 없이) `localStorage`에 기록합니다.
- 앱 전환·화면 잠금·탭 닫기·새로고침 순간에 아직 시트로 못 보낸 입력이 있으면 `sendBeacon`(또는 `keepalive` fetch)으로 즉시 내보냅니다.
- 앱을 다시 열면 **기기에 저장된 값이 먼저** 복원되고, 서버(시트) 값은 이 기기에 없는 칸이나 빈 칸만 채웁니다.
- 동승자 수는 시트에 `0`이나 빈 값이 있어도 무시하고 동승자 명단으로 다시 계산합니다.

## 입력값 ↔ 시트 칸

| 항목 | 칸 | 항목 | 칸 |
| --- | --- | --- | --- |
| 소속 | B4 | 운임 1행 일자·교통편·출발지·도착지·등급·금액 | B11 · C11 · D11 · E11 · I11 · J11 |
| 직급(직위) | H4 | 운임 2행 | B12 · C12 · D12 · E12 · I12 · J12 |
| 성명 | L4 | 운임 3행 | B13 · C13 · D13 · E13 · I13 · J13 |
| 출장 일시(시작~종료) | C5 | 운임 4행 | B14 · C14 · D14 · E14 · I14 · J14 |
| 출장(부임)지 | C6 | 총 동승자수 | C15 |
| 숙박비 상한액·실소요·사유 | C8 · E8 · J8 | 동승자 성명 1~4 | J16 · J17 · J18 · J19 |
| 첨부 | C21 | 신청일 | C23 |
| 신청인 성명 | C24 | | |

- 앱에서 고친 칸만 시트에 저장되고, 5초마다 시트의 변경을 받아옵니다(입력 중인 칸은 덮어쓰지 않음).
- 시트의 `출장 일시`(C5)는 `2026-11-30 ~ 2026-12-01` 같은 한 줄 문자열로 넣고, 앱이 다시 시작일·종료일로 나눠 읽습니다(같은 날이면 하루만).
- 이전 서식(출장목적·식비·소속/성명 3행 동승자)의 값은 시트의 `이전서식_백업` 탭에 그대로 남아 있습니다.
